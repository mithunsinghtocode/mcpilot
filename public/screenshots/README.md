# Screenshots Guide 📸

Add your screenshots to this folder with the following names:

## Required Screenshots

| Filename | Description | What to capture |
|----------|-------------|-----------------|
| `main-interface.png` | Main chat interface | The home screen with chat input and hot picks |
| `api-docs.png` | Swagger-style API docs | The API tab showing endpoint documentation |
| `server-panel.png` | Server panel | The "Try It" tab with form inputs |
| `servers-modal.png` | Servers browser | The modal showing all 40+ servers |
| `mode-toggle.png` | Mock/Real toggle | The panel showing the mode toggle buttons |

## How to Take Screenshots

### macOS
- **Full screen**: `Cmd + Shift + 3`
- **Selection**: `Cmd + Shift + 4`
- **Window**: `Cmd + Shift + 4`, then `Space`, click window

### Tips
1. Use a clean browser window (no bookmarks bar)
2. Set browser to ~1280x800 for consistent sizing
3. Use PNG format for best quality
4. Crop to show only relevant UI elements

## Recommended Dimensions

- **Width**: 1200-1400px
- **Format**: PNG
- **File size**: < 500KB (compress if needed)

## Compression Tools

- [TinyPNG](https://tinypng.com/) - Online compression
- [ImageOptim](https://imageoptim.com/) - macOS app
- `pngquant` - CLI tool

```bash
# Using pngquant
pngquant --quality=65-80 screenshot.png
```
